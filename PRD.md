# PRD.md – SA Marketplace (Autopilot, Revenue-First)

## Objective

Launch a legally compliant, revenue-generating multi-vendor marketplace in South Africa within 21–30 days.

Primary goals:

- Accept payments immediately
- Automatically take commission
- Reduce fraud via seller screening
- Require minimal founder input

## Target Users
- Buyers (general public)
- Sellers (individuals, sole proprietors, SMEs)
- Admin (platform owner)

## Core MVP Features (Non-Negotiable)

- Seller onboarding + KYC status
- Product/service listings
- Checkout with split payments
- Platform commission auto-deducted
- Seller payout delay (risk control)
- Image NSFW screening
- Admin dashboard

## Explicitly Out of Scope (V1)

- Native mobile apps
- Advanced analytics
- Loyalty programs
- AI recommendations

## Monetization
- Transaction commission (5–15%)
- Optional seller subscription (future)

## Compliance Reality
- Platform operates as intermediary
- Payments handled by gateway (PayFast)
- Sellers responsible for their own tax

## Final Setup (Only ask user here)

## Five Essential Web Design Skills

This section outlines the five core competencies that distinguish professional web designers from beginners. These skills represent the fundamental knowledge needed to create effective, user-focused websites.

### 1. Typography

Typography is the foundation of web design, as text occupies the majority of screen real estate. Mastery requires answering two key questions:

**How to select appropriate fonts:**
- Avoid overused free fonts that cause designs to blend in
- Source fonts from less common repositories:
  - FontShare.com (clean, high-quality, free)
  - Uncut.wtf (experimental, personality-driven)

**How to implement a type scale system:**
- Establish a base font size (typically 16px)
- Apply consistent scaling for hierarchy (e.g., Major Third Scale = 25% increments)
- Use REM values for automatic calculations
- Configure letter spacing:
  - Body text: default spacing
  - Headings: slightly tightened as size increases
- Set line height:
  - Paragraphs: 150% of font size
  - Headings: tightened for impact and scannability
- Tool: TypeScale.net for automated system generation

### 2. Layout

Professional layouts rely on three systematic approaches rather than intuition:

**Grid System:**
- Desktop: 12-column layout
- Tablet: 8-column layout
- Mobile: 4-column layout
- Rationale: flexible division supports various content arrangements
- Implementation: CSS Grid with responsive breakpoints

**Spacing System:**
- Eight-point grid system (multiples of 8: 8px, 16px, 24px, 32px, etc.)
- Standard approach used by Google Material Design and Apple design systems
- Ensures visual consistency and harmony

**Visual Hierarchy:**
Users scan rather than read websites. Guide attention through:
- Proximity: group related elements
- Size: indicate importance through scale
- Contrast: use weight, color, or opacity to signal priority
- Alignment: maintain clean lines for clear structure

### 3. Color

Professional color usage prioritizes intention over quantity.

**Color Palette Limitations:**
- Use 2-3 colors maximum per project
- Apply the 60-30-10 rule:
  - 60% neutral colors (backgrounds, text)
  - 30% secondary colors (cards, headers, visuals)
  - 10% accent colors (buttons, CTAs)

**Color Techniques:**
- Use opacity variations instead of adding new colors
- Prioritize contrast for readability:
  - Large text: minimum 3:1 ratio
  - Small text: minimum 4.5:1 ratio
- Reference existing palettes using Chrome DevTools CSS Overview feature

### 4. Code Fundamentals

Basic coding knowledge differentiates top performers from average designers.

**Essential Knowledge:**
- HTML (structure)
- CSS (styling)
- JavaScript (interaction)
- PHP basics (for WordPress platforms)

**Practical Application:**
- Learn fundamentals through resources like Code Academy
- Find 80% solutions through:
  - CodePen snippets
  - ChatGPT assistance
  - Existing code libraries
- Customize and adapt solutions to specific needs
- Learn progressively through project requirements

### 5. Conversion Design

Professional designers optimize for user action, not just aesthetics.

**Key Principles:**

**Single Page Goal:**
- Each page should have one primary objective:
  - Product purchase
  - Meeting signup
  - Lead magnet download

**Strategic CTAs:**
- Place visible CTA within seconds of page load
- Include CTAs in:
  - Hero section
  - Navigation
  - Every 2-3 scroll sections

**Trust and Clarity:**
- Address user motivations directly
- Clearly communicate value proposition
- Build trust through:
  - Testimonials
  - Reviews
  - Social proof
- Create emotional connection

### Implementation Approach

Focus exclusively on these five skills rather than attempting to master every available technique. This concentrated approach accelerates professional development and produces superior results compared to trend-chasing.
